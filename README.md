# StoreManager

Aplicación de gestión para una pequeña tienda desarrollada en Java.

Actualmente se trata de una versión de consola creada como primera etapa del proyecto.

## Funcionalidades

- Gestión de productos
  - Añadir productos
  - Buscar productos
  - Modificar productos
  - Eliminar productos
  - Consultar stock

- Gestión de clientes
  - Añadir clientes
  - Buscar clientes
  - Modificar clientes
  - Eliminar clientes

- Gestión de ventas
  - Registrar ventas
  - Consultar ventas
  - Actualización del stock después de una venta

## Tecnologías

- JavaFX
- Java
- Maven
- Git
- GitHub
