# StoreManager

Aplicación de gestión para una pequeña tienda desarrollada en Java.

Actualmente se trata de una versión de consola creada como primera etapa del proyecto.

## Funcionalidades

- Gestión de productos
  - Añadir productos
  - Buscar productos
  - Modificar productos
  - Eliminar productos
  - Consultar stock

- Gestión de clientes
  - Añadir clientes
  - Buscar clientes
  - Modificar clientes
  - Eliminar clientes

- Gestión de ventas
  - Registrar ventas
  - Consultar ventas
  - Actualización del stock después de una venta

## Tecnologías

- JavaFX
- Java
- Maven
- Git
- GitHub

## ¿Por qué una aplicación por consola?

Decidí desarrollar esta primera versión por consola para centrarme en la lógica y en los fundamentos de Java antes de trabajar en una interfaz gráfica.

La aplicación está organizada mediante clases y métodos, separando las diferentes responsabilidades del programa:

- Productos
- Clientes
- Ventas
- Detalles de venta
- Servicios para gestionar cada apartado

De esta forma, primero puedo comprobar que la lógica de la aplicación funciona correctamente sin depender de una interfaz gráfica.

Esta versión es también la base sobre la que evolucionará el proyecto. La idea es reutilizar la lógica desarrollada y convertir StoreManager progresivamente en una aplicación visual y más completa.
