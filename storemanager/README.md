# Store Manager

Prototipo de aplicación para digitalizar la gestión de una tienda facilitando el control de productos, clientes, stock y ventas sin necesidad de realizar estos procesos manualmente.

## Funcionalidades

- Gestión de productos
- Gestión de clientes
- Consulta de productos
- Búsqueda de productos por ID
- Búsqueda de productos por nombre
- Gestión de stock
- Registro de ventas
- Consulta de estadísticas

## Tecnologías

- Java
- Maven
- Programación Orientada a Objetos
- Git
- GitHub
